# サーモンラーンNW のマップ

このフォルダの画像は、[サーモンラーンNW](https://salmon-learn-nw.gungee.jp/)（管理人: ガンジーさん）のマップ画像です。
作戦図の土台として使うため、**作者の許可を得て**このアプリに同梱しています。

- 許可: 2026-11-17、X（@GungeeSpla）のDMで依頼し、「アプリ内（リポジトリ内）に直接画像を取り込んでいただいてまったく問題ございません」との返信をいただいた
- 依頼時に伝えた使い方: マップの上に作戦を描き込む／出典として「サーモンラーンNW」の名前とサイトへのリンクを画面に載せる／マップ画像だけを取り出して配る使い方はしない
- 画像の権利は作者にあります。このアプリ以外で使わないでください

## 中身
- `plain/<ステージ>_<潮位>.svg` … 線画（7ステージ×干潮・普通・満潮）。元の絵はそのままで、一番外側の `viewBox` と `width`/`height` だけを、描かれている範囲＋余白に書き換えて切り抜いている
- `model/<ステージ>_<潮位>.webp` … 立体風（NWにある5ステージ分）。元のPNG（3840px）を線画と同じ範囲で切り抜き、長い辺2048pxまでに縮めてWebPにした
- `maps.json` … `[幅, 高さ, 立体風があるか]`（NWの1016の枠での大きさ）。`board.js` の `NW_MAPS` に同じ値を書いている
- ステージ名: Shakeup=シェケナダム、Shakespiral=アラマキ砦、Shakelift=トキシラズいぶし工房、Shakeship=難破船ドン・ブラコ、Shakedent=ムニ・エール海洋発電所、Shakehighway=すじこジャンクション跡、Shakerail=どんぴこ闘技場

## 取り込み直すとき
`tools/nw_maps.py <出力先> <範囲のJSON>`。範囲はNWのマップのページをブラウザで開き、各SVGを1016pxの canvas に描いて透明でない範囲を測った値を渡す（2026-11-17に測った値は `tools/nw_maps_bbox.json`）。
**切り抜きの範囲や大きさを変えると、今ある作戦図の位置がずれる**（作戦図はこの大きさ×4の座標で覚えている）。変える時は、作戦図の座標を直す処理も一緒に作ること。マップを差し替えたら `sw.js` の `MAP_CACHE` の名前も変える（キャッシュ優先なので、変えないと古い画像が出続ける）。
